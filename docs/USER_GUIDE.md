# Sudoku ThreadScope — хэрэглэгчийн гарын авлага

## Зорилго
9×9 Sudoku-ийн **бүрэн бөглөсөн шийд** зөв эсэхийг C11/Pthreads хөдөлгүүрээр шалгана. 1, 11, 27 урсгалын горимыг сонгож, урсгал тус бүрийн үр дүн болон хугацааг харьцуулна. Энэ нь Sudoku-г автоматаар боддог програм биш.

## Windows дээр ажиллуулах
1. GitHub Actions-ийн хамгийн сүүлийн **ногоон ✓** Windows build-ийн `SudokuValidation_Windows_Ready` artifact-ийг татна.
2. ZIP-ийг **Extract All** хийнэ.
3. Задалсан хавтасны `SudokuValidation.exe`-г нээнэ. Python, GCC суулгах шаардлагагүй.
4. Хөтөч `http://127.0.0.1:8765/dashboard.html` хаягаар нээгдэнэ. Програмын серверийн цонхыг ажиллаж байх хугацаанд бүү хаа.

## Sudoku оруулах
- Самбарын нүдэнд 1–9 цифр бичнэ. Сум, Backspace, Undo, Clear ашиглаж болно.
- **Зөв жишээ**, **Алдаатай жишээ** товчоор туршина.
- **Sudoku .txt файл** сонгоно. Файл 64 KB-аас бага, `.txt` өргөтгөлтэй байх ёстой.
- Дэмжих формат: 9 мөр, мөр бүрд 9 цифр; эсвэл нийт 81 цифр. Зай, таслал, `|`, `+`, `-` тусгаарлагчийг үл тооцно; `#`-ийн арын хэсэг тайлбар. `0` болон `.` нь хоосон нүд; хоосон нүдтэй шийдийг зөв гэж тооцохгүй.
- Алдаатай файл сонговол самбар өөрчлөгдөхгүй, доор нь алдааны тайлбар гарна.

## Шалгах
1. **1**, **11**, эсвэл **27 урсгал** сонгоно.
2. **Sudoku шалгах** дарна. Сервер бодит C binary-г ажиллуулж `valid[]`, зөрчилтэй нүд, хугацааг буцаана.
3. Алдаатай нүд улаанаар тодорно. Алдааны дэлгэрэнгүй хэсэгт мөр, багана, 3×3 хэсгийн давхардал гарна.
4. **Урсгал бүрийн үр дүн** дэх карт дээр дарахад тэр урсгалын шалгасан нүднүүд цэнхэр хүрээтэй болно.

## Алхамчилсан дүрслэл
Шалгалт хийсний дараа **Алхмаар үзүүлэх** дарна. Хурдыг Удаан / Дунд / Хурдан гэж сонгож, **Зогсоох** товчоор зогсооно.
Дараалал: `pthread_create` → шалгах ажил → `pthread_join` → эцсийн үр дүн.

**Чухал:** Энэ нь шалгалтын **дараа** бодит C-ээс ирсэн үр дүнг сургалтын зорилгоор дарааллаар харуулдаг *дахин тоглуулалт*. Урсгал бүрийн бодит эхэлсэн/дууссан цаг, OS scheduler, зэрэгцээ ажиллагааны live бичлэг биш.

## Гүйцэтгэл
- **Бүх горимыг харьцуулах** нь горим тус бүрийг нэг удаа ажиллуулна.
- **Хугацаа хэмжих** нь горим бүрийг 3, 10 эсвэл 30 удаа ажиллуулж **медиан** хугацаа (µs) гаргана.
- Хамгийн бага хэмжигдсэн хугацаатай мөр тодорно. Маш жижиг ажилд урсгал үүсгэх зардал давамгайлж болно; үр дүн нь машин, ачааллаас хамаарна.
- **CSV татах** нь энэ удаагийн шалгалтын түүхийг хадгална.

## Архитектур
`dashboard.html` → локал `server.py` HTTP bridge → `sudoku_validator` C11/Pthreads → JSON үр дүн. Python нь зөвхөн UI-г C хөдөлгүүртэй холбодог; Sudoku шалгах үндсэн тооцоолол C дээр явагдана.

## Хамгаалалтын богино туршилт
1. Зөв жишээ + 11 урсгал → 11/11 ЗӨВ.
2. Алдаатай жишээ + 11 урсгал → мөр, багана, 3×3 хэсгийн зөрчил, улаан нүд.
3. T01, T02, T03 дээр дарах → шалгаж буй хэсэг тодрох.
4. Алхмаар үзүүлэх → дөрвөн үе шат, хурд солих, зогсоох.
5. Зөв `.txt` → самбар ачаалагдах; 80 цифртэй файл → алдаа гарч, самбар хэвээр үлдэх.
6. Хугацаа хэмжих → 1/11/27 медиан, хурдны харьцуулалт, CSV.

## Хязгаарлалт
- Програм зөвхөн локал `127.0.0.1` хаяг дээр ажиллана; нийтийн веб хостинг биш.
- Шалгах үйлдэл хийх үед л C хөдөлгүүр ажиллана; алхамчилсан UI бол үр дүнг тайлбарлах replay.
- Цагийн хэмжилт нь туршилтын хэмжилт бөгөөд бүх компьютер дээр 11 эсвэл 27 урсгал хурдан байна гэсэн баталгаа биш.
